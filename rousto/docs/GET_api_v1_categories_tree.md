# GET /api/v1/categories/tree

شجرة التصنيفات مع الخدمات المتداخلة — نقطة طرفية واحدة لشاشة الرئيسية في التطبيق.

- **Method:** `GET`
- **Path:** `/api/v1/categories/tree`
- **Auth:** لا (عام)
- **الغرض:** جلب التصنيفات وخدمات كل تصنيف في طلب واحد بدل `/categories` + `/services`

---

---

## القواعد

| القاعدة | التفاصيل |
|---------|----------|
| ترتيب التصنيفات | حسب `sort_order` تصاعدياً |
| ترتيب الخدمات | حسب `name_ar` أبجدياً |
| تصنيف `all` | يحتوي كل الخدمات النشطة |
| تصنيفات أخرى | تحتوي خدماتها فقط (`category_id`) |
| الخدمات غير النشطة | مستبعدة (`is_active = false`) |
| التصنيفات غير النشطة | مستبعدة |

---

## حالات الاستخدام

1. **شاشة الرئيسية (Flutter):** عرض شرائح التصنيفات + شبكة الخدمات
2. **فلترة محلية:** التبديل بين التصنيفات بدون طلبات إضافية
3. **الموقع:** عرض كتالوج الخدمات كاملاً

---

## مثال

```bash
curl http://localhost:8000/api/v1/categories/tree
```
