# Rousto UI (App + Web)

واجهات احترافية للتطبيق والويب مبنية بألوان هوية Rousto.

## التشغيل السريع

افتح الملف التالي مباشرة في المتصفح:

- `rousto-ui/index.html`

## الشعار الحقيقي

للاستخدام المباشر لشعارك الحالي:

1. ضع صورة الشعار في:
   - `rousto-ui/assets/rousto-logo.png`
2. يفضل ملف PNG بخلفية شفافة.

إذا لم يكن الملف موجودًا، سيتم عرض بديل تلقائي:

- `rousto-ui/assets/rousto-logo-placeholder.svg`
